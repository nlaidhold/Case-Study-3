# NFL Scoring Trends Case Study

### A DS 4002 Case Study by Noah Laidhold

## Overview

This case study analyzes how offensive strategy and game pace impact scoring trends in the NFL.

## Data

Data comes from nflfastR play-by-play data (2010–2024). The data was cleaned and prepared in R, then aggregated to weekly averages for analysis.

## Materials

The Materials folder contains all files needed to complete the case study:

- **nfl_weekly_dataset.csv** – final cleaned dataset used for analysis  
- **pbp_clean.csv** – intermediate cleaned play-by-play dataset  
- **data_set_cleaning.R** – R script used to clean and prepare the data   
- **nflfastR_reference.txt** – source and documentation for the dataset  
- **passing_trends_article.txt** – article providing context on NFL passing trends
